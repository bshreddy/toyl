\section{Statically \& Strongly Typed and Compiled}
Toyl v0.1 will be a Statically and Strongly Typed. All variables will be allocated on Stack or in Data Section. Types will not be implicitly converted, i.e., $int + float$ will not result in the $int$ being promoted to $float$.

\section{No heap or memory management}
To keep the implementation simple and manageable, v0.1 will not have any support for heap memory or any kind of runtime memory allocation. Eventually when this feature is added, Toyl will use Rust style Ownership+Swift style ARC to do automatic memory management.

\section{Builtin Datatypes}
v0.1 will only support \textit{int}, \textit{float}, \textit{boolean}, \textit{nil} and \textit{constant-size array}

\begin{itemize}
  \item \textit{int}: Toyl v0.1 has 4 int subtypes: \texttt{i8}, Numbers can start with: A digit, +/- signs, \texttt{0x} or \texttt{0X} for hexadecimal, \texttt{0o} or \texttt{0O} for Octal, \texttt{0b} or \texttt{0B} for Binary.

  \item \textit{float}: Toyl v0.1 has 3 subtypes: \texttt{fp16}, \texttt{fp32}, \texttt{fp64}. Floating point numbers can contain digits, period and +/- signs. If a floating-point number doesn't contain the decimal part, it can be suffixed with \texttt{f} or \texttt{F} to explicitly specify the literal is a floating-point number.

  \item \textit{boolean}: Defined using \texttt{bool}. Can be either \texttt{true} or \texttt{false}. Other types are not implicitly converted to Boolean, for example, 0 is not converted to \texttt{false}

  \item \textit{nil}: This is a temp. builtin type to allow variables to be null or nil. Later versions will not allow nil values for variables. All variables must have a defined values.

  \item \textit{constant-size array}: Constant fixed size arrays of other ``scaler'' datatypes.
\end{itemize}
