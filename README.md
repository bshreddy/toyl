# Toyl Programming Language

This is the repo for my toy-ish programming language, named "toyl" for "TOY programming Language." (pronounced same as "toil" cause it's gonna be a pain in my a** to get done.)

The goal of this project is
\begin{enumerate}
  \item Learn Compilers
  \item Learn the math behind computer science
  \item Eventually have a turing-complete programming language that supports Functional+Graph Operations
  \item Eventually have the compiler be self-hosted
  \item Learn technical writing
\end{enumerate}

The plan is to first have a basic turing-complete language with a custom backend and later switch to using LLVM/MLIR backend when I start playing around with Functional Programming Concepts or Graph Operations.

More details in [docs/pdf/toyl.pdf](docs/pdf/toyl.pdf)

Language Specification can be found in [docs/pdf/lang_spec.pdf](docs/pdf/lang_spec.pdf)
